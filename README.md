# Bulls and Cows

Number guessing game written as pure TypeScript functions. Task:
https://github.com/rolling-scopes-school/tasks/blob/master/fullstack-engineering/tasks/bulls-and-cows/README.md

## Scripts

- `npm run build` — compile TypeScript to `dist/` (native ES modules)
- `npm test` — run Vitest
- `npm run lint` / `npm run format`

Open `index.html` through any static server after `npm run build`.

See [DESIGN.md](./DESIGN.md) for data structures, complexity and clean code notes.
